# AI Registry — Anthropic (Inferred)

> **Inferred vendor repository.** This repo is maintained by the [AI Registry](https://github.com/eclipsefdn-ai-registry/ai-registry-core) project, not by Anthropic. It pre-seeds the registry with skills published by Anthropic at [github.com/anthropics/skills](https://github.com/anthropics/skills).
>
> *Based on an official public source. This does not indicate direct participation by Anthropic in the AI Registry.*

## What this repo contains

Skill approvals for all skills found under `skills/` in the [anthropics/skills](https://github.com/anthropics/skills) repository. The single approval file uses a glob source path (`skills/*`) so newly published skills are picked up automatically on the next registry consolidation.
